# Архитектура Ailbum

Конвейер хранит результаты каждого запуска в SQLite и экспортирует версионированный
`analysis.json`. Это позволяет добавлять следующие этапы без повторного чтения и
анализа оригиналов.

```text
каталог фото
    │
    ├─ загрузка + EXIF ── метаданные времени
    ├─ оценка качества ── резкость, экспозиция, итоговый quality
    ├─ признаки кадра ─── pHash + цветовая гистограмма ── группы дублей
    └─ лица ───────────── detector + embedding ────────── кластеры лиц
                                      │                         │
                                      └─ classic или YuNet/SFace└─ постоянные Person

SQLite + analysis.json + selection.csv
    │
    ├─ следующий этап: оценка эстетики и выбор лучших кадров
    └─ следующий этап: временные/географические события и сюжеты
```

## Границы модулей

- `io.py` — поиск файлов, загрузка с EXIF-поворотом, время съёмки.
- `metadata.py` — полное извлечение файловых, EXIF, GPS и контейнерных метаданных.
- `database.py` — схема SQLite, каталог изображений и история анализов.
- `cv/quality.py` — независимые метрики качества.
- `cv/similarity.py` — признаки всего изображения и группы похожих кадров.
- `cv/faces.py` — взаимозаменяемые бэкенды лиц.
- `cv/clustering.py` — кластеризация без тяжёлой зависимости от scikit-learn.
- `people.py` — контактные листы всех уникальных лиц одного человека.
- `pipeline.py` — оркестрация и стабильная схема результатов.
- `cli.py` — единственная точка взаимодействия пользователя на первом этапе.
