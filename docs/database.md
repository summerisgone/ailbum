# Локальная база изображений

Каталог хранится в SQLite, по умолчанию в `.ailbum/ailbum.sqlite3`. Файл находится
только на локальном компьютере и исключён из Git. SQLite работает в WAL-режиме,
внешние ключи включены.

## Схема

### `images`

Одна актуальная запись на абсолютный путь. Хранятся:

- абсолютный путь, корень источника и относительный путь;
- имя, расширение, размер, время изменения и создания файла;
- SHA-256 содержимого для поиска точных дубликатов;
- MIME-тип, формат, цветовой режим, ширина, высота и число кадров;
- ориентация, время съёмки, производитель и модель камеры, объектив, ПО;
- GPS-широта, долгота и высота;
- все прочитанные секции EXIF (`ifd0`, `exif`, `gps`, `interop`, `ifd1`) в JSON;
- контейнерные метаданные Pillow в JSON; бинарные ICC/EXIF-блоки представлены
  размером и SHA-256, а разобранные EXIF-значения сохраняются полностью;
- ошибка извлечения и признак отсутствующего после повторной индексации файла.

### `analysis_runs`

История запусков с конфигурацией, CV-бэкендом и сводкой. Повторный анализ не
затирает предыдущий запуск.

### `photo_analysis`

Метрики резкости, экспозиции и качества, отбраковка, группа похожих фотографий и
результат выбора для конкретного запуска.

### `people`

Постоянная сущность человека, не привязанная к одному запуску анализа:

- числовой `id` для CLI и стабильный UUID `public_id`;
- заданное пользователем имя;
- модель эмбеддинга и нормализованный центроид признаков лица;
- даты создания и обновления.

При следующем анализе центроид нового кластера сравнивается с известными людьми
той же модели. Совпавшие лица получают прежний `person_id`, поэтому имя и ручные
исправления не теряются.

### `faces`

Сущность найденного лица: изображение и запуск, координаты, уверенность детектора,
эмбеддинг, модель признаков, временный номер кластера и внешний ключ `person_id` на
постоянного человека. Одно изображение может содержать несколько лиц; один человек
может быть связан с лицами на многих изображениях.

Для оценки удачности портрета также сохраняются состояние левого и правого глаза,
вероятности их открытости, общий признак `both_eyes_open`, основное выражение,
уверенность, вероятность улыбки и полное распределение по семи выражениям в JSON.
Существующая база версии 2 обновляется до версии 3 автоматически без удаления
истории анализов.

## Команды

Только собрать метаданные, не выполняя CV-анализ:

```bash
uv run ailbum index ./data
```

Статистика и список:

```bash
uv run ailbum db stats
uv run ailbum db list --limit 20
uv run ailbum db list --limit 20 --json
```

Все сохранённые метаданные, история анализа и лица одного изображения:

```bash
uv run ailbum db show 1
```

Люди и все связанные с ними лица:

```bash
uv run ailbum people list
uv run ailbum people show 3
uv run ailbum people name 3 "Анна"
```

Если автоматическая кластеризация разделила одного человека на несколько записей,
их можно объединить. Первый ID сохраняется, остальные удаляются после переноса лиц:

```bash
uv run ailbum people merge 3 8 12
```

Контактный лист с уникальными фрагментами лиц человека:

```bash
uv run ailbum people compose 3 --output ./output/people/anna.jpg
```

Другой файл базы можно указать во всех командах через
`--database /path/to/catalog.sqlite3`.
